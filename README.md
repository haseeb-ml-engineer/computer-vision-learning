# Computer Vision Learning

A hands-on learning repository where I document my practice, experiments, and projects while learning Computer Vision, from image fundamentals toward deep learning and modern vision techniques.

I created it to keep my learning organized in one place, to build real implementation experience, and to make my progress easy to follow, for myself and for anyone else learning the same topics.

---

## About

This is a personal learning repository, not a finished course or a library. I add code, notes, and experiments as I work through Computer Vision topics, starting from the fundamentals and moving gradually toward more advanced material.

Some of the code may be rough or exploratory. The goal is understanding, not polish.

## What I'm Learning

My learning follows a rough progression:

1. **Images and image processing**: how images are represented and manipulated with NumPy and OpenCV.
2. **Classical Computer Vision**: filtering, thresholding, edges, contours, and features.
3. **Machine learning and deep learning for vision**: models that learn from image data.
4. **Modern vision techniques**: more advanced approaches, once the fundamentals are solid.

Steps beyond what appears in the [Progress](#progress) section are future learning goals, not completed work.
